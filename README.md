# 🌐 Hyperlink and Hypertext in HTML

This project demonstrates the difference between **hypertext** and **hyperlinks** using simple HTML examples.

---

## 🔗 What is a Hyperlink?

A **hyperlink** is a clickable link that connects one resource (like a web page) to another.

### ✅ HTML Example:
html
<a href="https://www.example.com">Visit Example</a>

. <a> is the anchor (link) tag.

. href is the attribute that defines the destination of the link.

. The text inside becomes clickable.

# 📄 What is Hypertext?
Hypertext refers to the text within an HTML document that is linked to other content.
It’s the visible, clickable content created using a hyperlink.

# ✅ Example:
<p>This is an example of <a href="https://www.wikipedia.org">hypertext</a>.</p>
